Estás desarrollando un sistema para una empresa de envíos llamada "QuickShip". Esta
empresa maneja diferentes tipos de paquetes, y cada tipo de paquete tiene características
particulares. También necesita construir órdenes de envío y generar copias de paquetes
existentes (por ejemplo, para hacer envíos múltiples del mismo tipo).
Parte 1: Patrón Factory (2.5 puntos)
Implementa una fábrica de paquetes que pueda crear instancias de diferentes tipos de
paquetes:
● SmallPackage
● MediumPackage
● LargePackage
Todos deben heredar de una clase abstracta o interfaz común Package. Cada tipo de
paquete tiene un peso y un costo base diferente.
Requisitos:
● Implementa una clase PackageFactory que crea objetos según el tipo
solicitado.
● Usa un enumerado o cadena para identificar el tipo de paquete.

YA

Parte 2: Patrón Builder (2.5 puntos)
Desarrolla una clase ShippingOrder, que representa una orden de envío. Esta puede incluir:
● Un paquete (instancia de Package)
● Dirección de envío
● Nombre del destinatario
● Seguro adicional
● Envío exprés

Requisitos:
● Usa el patrón Builder para construir objetos ShippingOrder.
● La clase ShippingOrderBuilder debe permitir agregar propiedades
opcionales de forma encadenada.

YA

Parte 3: Clonación (2.5 puntos)
Agrega la capacidad de clonar un paquete existente para repetir el mismo envío a
distintas direcciones.
Requisitos:
● Implementa el método clone() en las clases de paquetes.
● Demuestra cómo se pueden hacer copias de un paquete y usarlas para
generar nuevas órdenes de envío.

YA

Parte 4: Integración y Pruebas (2.5 puntos)
Crea una clase Main con un método main() donde:
● Se cree al menos un paquete de cada tipo usando la fábrica.
● Se construye una orden de envío usando el builder.
● Se clona un paquete y se crean nuevas órdenes de envío basadas en la copia.
● Se imprimen los detalles de las órdenes para verificar el funcionamiento del sistema
