1. Modelado básico de clases (15 puntos)
Crea las siguientes clases:
● Pelicula: contiene título, año, género y calificación.
● Usuario: tiene nombre, tipo de usuario, lista de películas vistas.
● CatalogoPeliculas: mantiene una lista de todas las películas disponibles.

YA

2. Herencia y polimorfismo (10 puntos)
Crea la jerarquía:
● Usuario (clase base)
● UsuarioEstandar y UsuarioPremium (subclases)
Cada subclase debe sobrescribir un método verContenido() que indique cuántas películas
puede ver según el tipo de usuario.

YA

Patrón Builder (20 puntos)
Implementa el patrón Builder para crear objetos Usuario de manera flexible.
Debe permitir construir objetos con campos como:
● Nombre
● Edad
● Preferencia de género
● Lista inicial de películas vistas
Construye instancias de UsuarioEstandar o UsuarioPremium.

4. Patrón Singleton (10 puntos)

6. Integración del sistema (35 puntos)
En una clase Main, realiza lo siguiente:
● Crea al menos 5 películas y agrégalas al catálogo.
● Crea al menos 2 usuarios utilizando el Builder y la Factory.
● Muestra cómo se construyen los usuarios con distintos datos.
● Cada usuario debe ver contenido usando verContenido().
● Agrega películas vistas a cada usuario y muestra sus listas.
Se evaluará la correcta integración de todos los componentes, el uso adecuado de los
patrones y la claridad del código.
